# Toolkit for Navigating Collaboration

I'm so glad you want to use this worksheet. It is designed for those collaborations that feel tricky, unclear, or simply
important enough to look at more consciously.
Whenever you're facing one of these situations - pull it out.
Go through the questions and see how the conversation changes.

👉 **And then ... please tell me what happened.**

I would genuinely love to hear via [LinkedIn](https://www.linkedin.com/in/maike-sestendrup/?locale=en-US) how the ideas from my talk resonated with you:
- Which collaboration did you try to improve with this worksheet?
- Did it help?
- What did you notice - and which next step did you choose?

## ⚠️ Usage Note
This is an interactive PDF. You can fill in the purple fields and click the checkboxes in a compatible
PDF viewer or browser.

### iPhone users:
If you save the PDF locally on your iPhone, make sure to open it from the Files app in Apple Preview, rather than in your web browser, which unfortunately happens by default if you click on
en" after the download.
- **Apple Preview:** Double-tap a purple text field to start typing. If you use the Fill tool, please note that the checkboxes cannot be selected while it is active - turn the Fill tool off to use them.
- **Google Drive:** If you save the PDF to Google Drive, tap Fill form at the bottom before filling it in.
